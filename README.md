# EV Swap & Charging Rollout — Instamart Pods

ROI v2 dashboard — cost-aware rate card, blocker action cascades, editable rate card.

**Live:** https://shuttle-ci-user1.github.io/ev-rollout-dashboard-roi/

Open `index.html` directly in any browser — fully self-contained (no server, no build).

## What's in v2
- **ROI tab:** summary header (total capex, monthly/annual savings, blended payback), per-station cards (one-time cost + monthly/annual saving), editable collapsible rate card, methodology footnote.
- **Blocker cascades:** to-do decision tree under each blocker lane (space, power, vendor, NOC).
- **Rate card:** Delhi / Gurgaon / Bangalore / Mumbai (additive & bundled modes, tiered above limit).
